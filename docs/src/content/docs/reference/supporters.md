wisp.place is one person's passion project, built in spare time to be permanently free.

If you do want to offer support, be awesome, or gimme money:

- [GitHub Sponsors](https://github.com/sponsors/WaveringAna)
- [Ko-fi](https://ko-fi.com/waveringana)

Any amount is fine, and donations just help keep it running. Leave your atproto handle somewhere (in the donation note, or message [@nekomimi.pet](https://bsky.app/profile/nekomimi.pet)) so your supporter features can be turned on.

## Supporter benefits

Supporters can benefit from a few simple 'power user' features:

- You can use unlimited custom `*.wisp.place` subdomains (by default you're limited to 3)

- You have a 700 MB per-site cap (rather than the usual 300 MB)

- You can use your sites as a static PDS (see [wisp.place's docs](/guides/static-pds/) and the [at-SDP](https://tangled.org/byjp.me/at-sdp))
